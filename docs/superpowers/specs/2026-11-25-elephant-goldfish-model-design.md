# 加入 Elephant-Goldfish Model 精選 Repo

## 目的

將使用者指定的 `google/elephant-goldfish-model` 加入個人手動精選清單，讓訪客能搜尋、依分類瀏覽並前往 GitHub。

## 做法與取捨

沿用現有 repo 卡片和唯一資料來源 `assets/catalog.mjs`，放入「AI 代理、寫作與研究」分類，並補上依 GitHub 專案說明撰寫的繁體中文用途與挑選理由。這個分類已涵蓋 AI agent 工具；另開單筆分類會增加不必要的篩選項。

## 範圍與限制

- 清單由 10 筆增為 11 筆；保留現有資料、搜尋、分類、排序和部署方式。
- Stars 仍是手動快照，不串接 API。GitHub 頁面目前只顯示約 22.8k；新增時以 22,800 作為近似快照，並標示記錄日期，不聲稱是精確即時值。
- 更新 catalog 測試，涵蓋新增項目的資料、連結、搜尋、分類及清單排序。
- 不新增網站分類、依賴或 UI 功能。
