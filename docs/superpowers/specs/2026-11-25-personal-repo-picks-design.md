# 個人精選 Repo 清單設計

## 目的

將目前以 AI agent 工具為主題的目錄，改為作者手動挑選與介紹的好 GitHub repo 清單。訪客能看懂每個 repo 的用途，也能知道作者推薦它的理由。

## 範圍與限制

- 保留原生靜態網站、現有卡片呈現、搜尋、分類、排序與響應式版面。
- 更新頁面標題、導覽、主視覺、區段及頁尾文字，移除只適用於 skills 或 AI agent 工具目錄的定位。
- 卡片以 repo 用途描述和作者的推薦理由為主；Stars 與更新日期只是參考資訊，不作為推薦依據。
- 保留手動維護的 repo 清單，不串接 GitHub pinned repositories 或 API。
- 先以目前收錄的 10 個 repo 為內容範圍；不新增 repo，也不捏造作者個人推薦理由。若缺少明確推薦理由，使用現有資料能支持的具體介紹，不冒稱為作者的個人經驗或背書。

## 方法與取捨

1. **一般 repo 目錄**：以廣泛 repo 搜尋與 Stars 排序為主。改動較少，但仍像中性的資料目錄，無法清楚表達個人精選。
2. **個人精選清單（採用）**：以作者手動挑選與介紹為主，卡片保留現有 repo 資料及瀏覽互動，Stars 降為輔助資訊。最符合「我挑選的好 repo」定位；介紹文案須忠於現有資料，不虛構推薦經驗。

## 實作決策

沿用 `assets/catalog.mjs` 作為唯一靜態資料來源，沿用既有卡片和互動，不引入框架、依賴或 GitHub 同步。調整頁面文案與資料欄位／卡片呈現，使網站清楚說明清單由作者手動挑選；若要新增獨立的推薦理由欄位，只填有內容依據的文案。

## 驗收

首頁與卡片不再將清單描述為只收錄 skills 或 AI agent 工具；能看出這是作者手動挑選的 repo 清單；既有搜尋、分類、排序及 GitHub repo 連結仍可使用；Stars 文案不暗示它決定推薦品質。
